# Machine Learning – CIE 2 Activity 1
# Dataset Preparation Activity

# Project Description
This project focuses on preparing a customer dataset for future machine learning tasks.

# Dataset Features
* Customer_Name
* Last_Purchase_Date
* Total_Spend
* Region

# Activities Performed
1. Dataset loading and inspection
2. Missing-value analysis and handling
3. Duplicate and data-quality checks
4. Exploratory Data Analysis (EDA)
5. Data visualisation
6. Categorical encoding
7. Numerical feature scaling
8. Saving the prepared dataset
